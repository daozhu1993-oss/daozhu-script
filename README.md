## 信息架构 (Information Architecture)

- `/` **定位落地页**：一句话定位 + 10年职业背书（《一纸还乡》55集、《冲喜后》33集）+ 三大路径入口 + 免费开局包换邮箱
- `/guides` **方法论库 (Guides)**：按知识主题组织的 evergreen 教程（结构与节奏、爽感公式、前3集留人、AI漫剧工作流等）
- `/teardowns` **拆爆款 (Teardowns)**：用编剧眼拆解具体爆款短剧/漫剧，附带爽点节拍波形与可抄要点
- `/templates` **模板工具库 (Templates)**：工业化脚手架（分集断章节奏卡、人物欲望冲突表、Prompt字典）
- `/works` **商业战绩 (Works)**：真实上线商用作品背书与复盘
- `/start` **新手路径 (Start)**：从 0 到写出第一个商用本子的五步通关指南
- `/about` **关于岛主与合作 (About)**：1对1改本急诊室、全案定制、训练营咨询
