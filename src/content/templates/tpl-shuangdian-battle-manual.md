## 怎么用这份手册（30 秒读法）

写一部新剧，按这个顺序走：

1. **定赛道**（Part 2 配方表选一行）→ 男频还是女频、什么题材。
2. **定主爽点 2–3 种**（配方表"主爽点+辅爽点"列）→ 这是全剧情绪主轴。
3. **设计够扎心的憋点**（Part 3 作战卡"憋点清单"）→ 憋不够，后面全白给。
4. **排集纲 + 标卡点**（Part 1 节奏尺 + Part 3 卡点位置）→ 一卡/二卡前埋最强钩。
5. **每集用钩子模板收尾**（Part 3 每集钩子模板）→ 切在爆发前半秒。

> 💡 **一句话心法**：**短剧不是写故事，是"持续开情绪缺口，再持续填"。你写的每一秒，要么在勾人、要么在给情绪。**

# Part 1 · 短剧爽点体系速查（6 模块）

## ① 四种情绪货币（底层缺口）

| 货币 | 内核 | 适用 | 备注 |
|---|---|---|---|
| **爽** | 出气·打脸·逆袭·碾压 | 男女频通吃 | 最硬的货币 |
| **甜** | 心动·宠溺·双向奔赴 | 女频甜宠核心 | 甜蜜情绪资产 |
| **虐/揪心** | 误会·分离·危机·委屈 | 为"爽"和"甜"蓄力 | 本身也是黏性 |
| **好奇** | 悬念·身份未揭·伏笔未收 | 牵引点下一集 | 钩子的燃料 |

> **上头规律**：持续制造“情绪缺口”，再持续填补。缺口开得越大、憋得越久，填补时越爽。

## ② 爽点类型库（立项先选 2–3 种当主轴）

- **身份反转类（最强·近乎万能）**：扮猪吃老虎 / 马甲掉落 / 打脸连环
- **逆袭复仇类**：重生复仇 / 绝境翻盘 / 反杀（将计就计）
- **情感类（甜/虐）**：火葬场 / 双强宠 / 先婚后爱·破镜难圆
- **能力碾压类**：专业降维打击 / 金手指碾压

> **配方原则**：一条**主爽点线**贯穿全剧（如"扮猪吃老虎+打脸"），配**辅助爽点**交替释放（如情感线"火葬场"），防单一疲劳。

## ③ 爽感产生机制：憋 → 临界 → 爆 → 余爽（短剧命门）

> ⚠️ **新手第一死因：没憋就爽。** 爽感是落差，落差来自前面的压抑。

- **憋**：要**具体、扎心**——让观众看见婆婆当众羞辱、前夫施舍般丢工作，不是抽象说"她很惨"。
- **临界**：憋到观众"再不还手我就划走"的那一刻，是爆发的最佳时机。太早不够爽，太晚会流失。
- **爆**：打脸/反转/逆袭，一击到位。
- **余爽（绝不能省）**：对手震惊哑口的脸、旁人“卧槽”的反应、主角云淡风轻的收尾台词。**爽点的余韵一半在对手脸上。**

## ④ 钩子公式（每集收尾，四种轮换）

| 钩型 | 玩法 | 例 |
|---|---|---|
| **悬念钩** | 抛一个未解的问题 | 那张纸写着什么？门外是谁？ |
| **反转钩** | 结尾意外反转，颠覆本集认知 | 她以为赢了，对方嘴角一扬——是圈套 |
| **危机钩** | 把主角推进更大危机 | 他知道了她的真实身份 |
| **期待钩** | 让观众预感"下一集要爽了" | "明天的董事会，我看谁笑到最后" |

> 🔑 **最强钩子** = 把揭晓切在爆发前半秒黑屏（马甲刚要掉、杀招刚要出口、震惊表情刚起）。  
> 🚫 **收尾禁忌**：别用“今天真开心”“我们回家吧”这类情绪落地台词——情绪一落地，观众就走。

## ⑤ 节奏尺

- **黄金 3 秒 / 黄金一集**：第 1 集前 3 秒甩最大冲突或最强钩（离婚、灵堂惊变、当众羞辱、重生睁眼），**绝不上 logo、不交代背景、不寒暄**。第 3 集前给第一个像样的爽点。（高潮点从第 5 分钟推到第 7 分钟，留存掉两成——**宁早勿晚**。）
- **3-30-90 法则**：每 **3 秒**画面/信息有变化；每 **30 秒**一个小转折；每 **3 分钟**（约 1.5 集）一个情绪峰值。写完拿这把尺量一遍。
- **反转密度**：每集**至少一次预期违背**（反转/意外/打脸/揭晓其一）。
- **付费卡点（国内三卡）**：一卡约 **8–12 集**（吊胃口）、二卡约 **26–30 集**（引爆充值）、三卡后段（传播裂变）。**卡点前那集 = 到此为止最强的钩子。**

## ⑥ 七种塌房点（诊断"不爽"照着查）

1. **没憋就爽** → 补憋的过程
2. **憋太久憋死**（一路挨打不还手）→ 缩短憋屈段，或插小爽点续命
3. **反派太蠢** → 让反派强、有理、有威胁
4. **没余爽**（打脸完就切走）→ 补对手/旁人反应 + 主角收尾台词
5. **钩子软**（情绪落地了）→ 揭晓切在爆发前半秒
6. **主角没软肋**（全程碾压不揪心）→ 中段给一次真正的跌倒
7. **爽点单一重复** → 主辅爽点交替，情感线与逆袭线穿插

# Part 3 · 作战卡（憋点清单 + 每集钩子模板 + 卡点位置）

## 通用 · 每集钩子模板（任何赛道套用）

一集 1.5–2 分钟 ≈ 550–800 字，三段式：

```text
【开头 3 秒】接住上集钩子 / 立刻甩新钩——绝不日常寒暄开场
【中段】做透一个情绪支点：一个爽点 或 一个强钩（宁可一集只做一件，做透）
        · 台词短狠口语，单句 8–12 字，杜绝水台词
        · 内心戏用 OS/VO 外化，不写小说式长段心理
        · 打脸/爽点必带余爽镜头（对手脸+旁人反应+主角收尾）
【结尾】钩子收尾——切在观众最想知道"下一秒"的地方黑屏
```

**全剧钩子锚点（排大纲先标这几处）**：第 1 集最大憋屈 → 第 3 集第一个爽点 → 一卡(8–12)最强钩 → 二卡(26–30)引爆充值 → 中段(30–60)至暗时刻 → 结局马甲全掉+题眼收尾。

## 作战卡 A ·【冲喜 / 替嫁 · 先婚后爱】（女频实战）

**主爽点**：先婚后爱 + 双向揭马甲 ｜ **辅爽点**：火葬场（悔婚方/苛待方追悔）、甜

**憋点清单**（越具体越扎心，挑 3–4 个铺前 10 集）：
- 被家族当筹码替嫁/冲喜，嫁给“病重将死”的夫君守活寡
- 婆家/妯娌当众羞辱：赔钱货、克夫命、冲喜工具
- 亲妹/继母抢走原本属于她的婚事/家产，还来踩低炫耀
- 夫君表面病秧子、被全府轻视，实则深藏不露

**关键集钩子锚点**：
- **第 1 集**：花轿/灵堂开局——她以为拜的是牌位，红盖头掀开，“死人”睁眼开口。（危机钩+悬念钩）
- **第 3 集**：她一手医术/持家本事初露，夫君眼神微变——他没那么简单。（第一个爽点+期待钩）
- **★一卡(8–12)**：婆家逼她让位/休书上门，她当面亮出第一重马甲（名门医女/隐藏嫡女），全府哗然，黑屏。
- **★二卡(26–30)**：夫君真实身份（王爷/首富/大佬）揭晓当口切断，引爆充值。
- **中段(30–60)**：误会/夺权/仇家反扑，两人分离，主角跌一大跤。
- **结局**：双马甲全掉 + 悔婚方火葬场追悔 + 双强并肩，题眼收尾。

**招牌桥段**：拜堂惊变 / 病夫忽然护妻掀桌 / 互揭马甲“原来你也是” / 悔婚家族跪求认亲被拒。

## 作战卡 B ·【神医 / 香医 · 医女】（女频实战）

**主爽点**：专业降维打击（医术/制香碾压） ｜ **辅爽点**：打脸伪专家、甜宠、反杀仇家

**憋点清单**：
- 被当江湖骗子/庶女/下堂妇，医术无人信
- 名医/太医当众嘲讽“你也配谈医”，众人哄笑
- 被诬陷医死人/用毒，百口莫辩
- 仇家握权，她有真本事却拿不出证明的机会

**关键集钩子锚点**：
- **第 1 集**：太医判死的人/贵人危在旦夕，她一句“还有救”，全场嗤笑——她当场动手。（憋+期待钩）
- **第 3 集**：一针/一方救回，伪专家社死，第一个专业打脸落地。（爽点+余爽：专家脸色骤变、旁人惊叹、她转身平静）
- **★一卡(8–12)**：更大人物病危、伪专家使绊，她被逼绝境接下“必死之局”，黑屏。
- **★二卡(26–30)**：她的真实身份（医圣传人/隐藏郡主）或惊天医案真相揭晓当口切断。
- **中段(30–60)**：被栽赃医杀要人、声名尽毁，至暗时刻。
- **结局**：以医术翻案 + 反杀仇家 + 身份揭晓 + 情感收获，题眼收尾。

**招牌桥段**：绝症当场逆转 / 揭穿“神医”是骗子 / 以毒攻毒反杀下毒者 / 权贵排队求诊打脸曾经的羞辱者。

> 💡 **专业打脸的完整节奏范例（可直接仿写）**：  
> **憋**：伪专家嘲讽“你的方子还不如我一根银针”，众人哄笑，主角被推搡后退。  
> **临界**：观众替她憋屈——她明明是对的，却没人给她证明的机会。  
> **爆**：她一句“这脉是喜脉不是绝症，你要下的针会一尸两命——你敢扎吗？”  
> **余爽**：专家的手僵在半空、冷汗直下；围观者从哄笑变惊呼；主角转身就走，背影平静。

## 作战卡 C ·【重生复仇】（女频/男频通用 · 最万能）

**主爽点**：重生复仇 + 先知碾压 + 精准反杀 ｜ **辅爽点**：火葬场、打脸虐渣

**憋点清单**（重生前的"前世"要闪回够惨）：
- 前世被最信任的人（枕边人/闺蜜/兄弟）背叛害死
- 倾其所有却落得家破人亡/惨死收场
- 仇人踩着自己上位，还假惺惺

**关键集钩子锚点**：
- **第 1 集**：前世惨死最后一秒 → 睁眼重生回**关键节点**（签离婚协议/被害当天）。（最强开局钩）
- **第 3 集**：利用先知，第一次精准打脸/避坑，观众“这世不一样了”。（爽点+期待钩）
- **★一卡(8–12)**：布局初见成效，仇人开始反扑、察觉异常，黑屏。
- **★二卡(26–30)**：一个大仇人被反杀/身败名裂的当口切断，引爆充值。
- **中段(30–60)**：仇人狗急跳墙、伤及主角在意之人，至暗一跤。
- **结局**：仇人全线崩塌 + 火葬场追悔 + 主角掌控全局，题眼收尾。
